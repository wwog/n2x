逐项观察迁移过程
先选择目标并准备，再每次完成一个业务项，例如建表、导入全部 JSON、搬迁目录。一个版本包含多个业务项，全部成功后才更新版本。
“准备”会加载迁移路径和已有进度，不立即执行数据操作。“完成下一项”也可能完成一次版本确认。
测试失败与重启恢复
安排一次测试故障。下次写入 v2 的姓名合并结果时，撤销该批 SQL 写入并报错，迁移版本保持 v1。点击本按钮不会立刻执行迁移。
故障排除后，让停止的任务可以继续。此按钮不会立即执行数据操作；然后点击“完成下一项”，或“自动迁移到”原目标。已经确认完成的项目会保留。
重新创建迁移执行器，保留数据库、文件和已保存的进度。随后选择原来的目标，点击“准备逐项迁移”，再继续执行。用于检查中途退出后能否恢复。
